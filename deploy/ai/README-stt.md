# پیش‌نویس صورتجلسه از فایل صوتی جلسه

دبیر فایل صوتی یا فیلم جلسه را در زبانهٔ «مستندات» جلسه بارگذاری می‌کند. فرمت‌های پذیرفته MP3، M4A، WAV، OGG، AMR، MP4 و WebM هستند و حجم فایل تا ۲ گیگابایت می‌تواند باشد. سپس در زبانهٔ «صورتجلسه» دکمهٔ «تبدیل به متن و تهیهٔ پیش‌نویس» را می‌زند. پس از آن:

1. **تبدیل گفتار به متن (Whisper):** فایل به متن فارسی زمان‌دار تبدیل می‌شود، مثلاً `[00:12:05] …`. نام حاضرین و عنوان بندهای دستور جلسه هم به موتور داده می‌شود تا درست نوشته شوند.
2. **تهیهٔ پیش‌نویس (Ollama):** یک مدل زبانی روی همین سرور از روی متن، دو بخش می‌نویسد:
   * «شرح مذاکرات جلسه» به ترتیب بندهای دستور جلسه؛
   * «پیش‌نویس مصوبات» همراه با بند مرتبط، و مسئول و مهلت اگر در جلسه گفته شده باشد.
3. **بازبینی دبیر:**
   * دبیر متن شرح مذاکرات را اصلاح می‌کند و با «افزودن به صورتجلسه» آن را به‌صورت یک نسخهٔ جدید به پیش‌نویس صورتجلسه اضافه می‌کند.
   * هر مصوبه با «ثبت مصوبه…» در فرم معمول ثبت مصوبه باز می‌شود؛ مسئول، مهلت و دستگاه اجرایی را دبیر تعیین می‌کند.
   * تا وقتی دبیر تأیید نکند، چیزی خودکار ثبت نمی‌شود.

پردازش در پس‌زمینه انجام می‌شود. وقتی تمام شد، به دبیر اعلان داده می‌شود؛ لازم نیست صفحه باز بماند. متن پیاده‌شده فقط برای دبیر و رئیس کمیسیون قابل مشاهده است. درخواست، لغو و افزودن به صورتجلسه در رویدادنگاری ثبت می‌شوند.

اگر موتور گفتار به متن نصب نباشد ولی مدل زبانی باشد، دبیر می‌تواند متن پیاده‌شدهٔ جلسه را خودش وارد کند (یا یک فایل txt بارگذاری کند) و فقط پیش‌نویس را بگیرد.

## امنیت

هر دو موتور باید روی سرور اتاق یا سروری در شبکهٔ داخلی اتاق اجرا شوند. فایل صوتی جلسات اطلاعات محرمانه است و نباید به سرویس‌های اینترنتی مثل OpenAI فرستاده شود.

## منابع لازم

| بخش | پیشنهاد | حافظه | سرعت تقریبی روی پردازنده (بدون کارت گرافیک) |
|---|---|---|---|
| گفتار به متن | Whisper large-v3 (یا large-v3-turbo) | ۴ تا ۶ گیگابایت | جلسهٔ دوساعته: یک تا چند ساعت، بسته به تعداد هسته‌ها |
| پیش‌نویس | `gemma3:12b` (فارسی خوب) | حدود ۹ گیگابایت | چند دقیقه تا نیم ساعت |
| پیش‌نویس روی سرور کوچک | `gemma3:4b` | حدود ۴ گیگابایت | سریع‌تر، با کیفیت کمتر |

* با کارت گرافیک NVIDIA هر دو مرحله چند برابر سریع‌تر می‌شوند.
* کارها یکی‌یکی انجام می‌شوند و Ollama پس از ۵ دقیقه بیکاری مدل را از حافظه خارج می‌کند. بنابراین روی سرور ۱۶ گیگابایتی، Whisper و `gemma3:12b` پشت سر هم اجرا می‌شوند و همزمان حافظه نمی‌گیرند.

## ۱. مدل زبانی (Ollama)

همان موتور «مصوبات مشابه» است. اگر هنوز نصب نشده، اول `bash deploy/ai/install.sh` را اجرا کنید. سپس:

```bash
cd ~/kx21
docker compose --profile ai exec ai ollama pull gemma3:12b
echo "AI_CHAT_MODEL=gemma3:12b" >> .env
docker compose up -d api
```

* **سرور بدون اینترنت:** فایل GGUF مدل را روی رایانهٔ دیگری دریافت و با `ollama create` وارد کنید (همان روش `install.sh` برای bge-m3).
* **Ollama روی سرور دیگری در شبکه:** `AI_BASE_URL=http://نشانی-آن-سرور:11434/v1` را در `.env` بنویسید.
* `AI_CHAT_CONTEXT`: اندازهٔ پنجرهٔ متن مدل؛ پیش‌فرض 16384. جلسه‌های طولانی بخش‌به‌بخش خلاصه و سپس ترکیب می‌شوند.

## ۲. گفتار به متن (Whisper)

هر سرویسی که رابط سازگار با OpenAI (`/v1/audio/transcriptions`) داشته باشد قابل استفاده است. دو گزینهٔ متداول:

* **faster-whisper با پروژهٔ speaches:** در ایمیج Docker آن مدل `Systran/faster-whisper-large-v3` را بارگذاری کنید و `STT_MODEL` را همان نام بگذارید.
* **whisper.cpp:**
  ```bash
  whisper-server --host 0.0.0.0 --port 8001 -m ggml-large-v3.bin -l fa --convert \
                 --inference-path /v1/audio/transcriptions
  ```
  گزینهٔ `--convert` به ffmpeg روی همان سرور نیاز دارد تا فایل‌های MP3 و MP4 خوانده شوند.

سپس در `.env` سامانه بنویسید:

```bash
STT_BASE_URL=http://نشانی-سرور-whisper:8001/v1
STT_MODEL=Systran/faster-whisper-large-v3   # برای whisper.cpp هر نامی پذیرفته است
```

و اجرا کنید:

```bash
docker compose up -d api
```

اگر Whisper روی همین سرور و بیرون از Docker اجرا می‌شود، از نشانی `http://172.17.0.1:8001/v1` استفاده کنید. پورت 8001 را فقط برای شبکهٔ داخلی باز کنید.

تنظیمات دیگر:
* `STT_LANGUAGE`: زبان گفتار؛ پیش‌فرض `fa`.
* `STT_TIMEOUT_MINUTES`: حداکثر زمان انتظار برای یک فایل؛ پیش‌فرض ۲۴۰ دقیقه.

## بررسی

پس از راه‌اندازی، در زبانهٔ «صورتجلسه» یک جلسه در وضعیت پیش‌نویس، کادر «پیش‌نویس صورتجلسه از فایل صوتی» فعال می‌شود. اگر کاری ناموفق شود، متن خطا (مثلاً «اتصال به موتور برقرار نشد» یا «مدل … روی موتور نصب نیست») همان‌جا نشان داده می‌شود و دکمهٔ «تلاش دوباره» دارد. اگر متن پیاده‌شده قبلاً آماده شده باشد، تلاش دوباره فقط پیش‌نویس را از نو می‌سازد.
