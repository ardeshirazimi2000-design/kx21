# وبینار داخلی سامانه (Jitsi Meet)

برای جلسات «آنلاین» و «ترکیبی»، سامانه یک اتاق وبینار اختصاصی روی سرور خودتان می‌سازد. نرم‌افزار وبینار Jitsi Meet است: متن‌باز است و روی همین سرور اجرا می‌شود، پس به سرویس خارجی وابسته نیست.

- فقط مدعوین همان جلسه و نمایندگان معرفی‌شده می‌توانند وارد شوند. سامانه برای هر نفر یک توکن امضاشده می‌سازد و بدون آن ورود ممکن نیست.
- رئیس، نایب‌رئیس و دبیر «مدیر جلسه وبینار» هستند و می‌توانند میکروفون دیگران را ببندند یا کسی را خارج کنند. بقیه شرکت‌کننده عادی هستند.
- ورود به وبینار هنگام باز بودن اعلام حضور، حضور «آنلاین» را هم ثبت می‌کند و در حد نصاب حساب می‌شود.
- رئیس و دبیر از ۳۰ دقیقه پیش از شروع جلسه می‌توانند وارد شوند و بقیه پس از باز شدن اعلام حضور.

## پیش‌نیازها

1. یک دامنه یا زیردامنه که رکورد A آن به آی‌پی سرور اشاره کند؛ مثلاً `webinar.maliyarapp.ir`.
2. پورت‌های **80/tcp**، **443/tcp** و **10000/udp** آزاد باشند و در فایروال سرور و پنل ارائه‌دهنده سرور باز شوند. صدا و تصویر از پورت 10000/udp عبور می‌کند.
3. منابع پیشنهادی: ۲ هسته پردازنده و ۴ گیگابایت حافظه برای حدود ۳۰ تا ۵۰ شرکت‌کننده هم‌زمان. پهنای باند خروجی برای هر نفر حدود ۱ تا ۲ مگابیت بر ثانیه در نظر بگیرید.

## نصب

```bash
cd ~/kx21
git pull
sudo bash deploy/webinar/install.sh webinar.maliyarapp.ir ایمیل-شما@example.com
```

اسکریپت این کارها را انجام می‌دهد:

- بررسی دامنه و آزاد بودن پورت‌ها.
- ساخت رمزها.
- دریافت گواهی SSL رایگان (Let's Encrypt).
- اجرای وبینار.
- اتصال سامانه به وبینار: سه متغیر `WEBINAR_*` را به `.env` اصلی اضافه و API را دوباره اجرا می‌کند.

اجرای دوباره اسکریپت مشکلی ندارد و رمزهای قبلی حفظ می‌شوند.

اگر Docker Hub روی سرور در دسترس نیست، یک میرور معرفی کنید:

```bash
REGISTRY_MIRROR=docker.arvancloud.ir sudo -E bash deploy/webinar/install.sh webinar.maliyarapp.ir ایمیل-شما@example.com
```

## نکات

- **مرورگر:** کروم، فایرفاکس یا اج جدید. در گوشی، دکمه «ورود به وبینار» در اپ، وبینار را در مرورگر گوشی باز می‌کند.
- **باز شدن داخل صفحه جلسه:** تا وقتی خود سامانه روی `http://…:8000` است، وبینار در پنجره جدید باز می‌شود؛ مرورگرها دوربین و میکروفون را فقط در صفحه https اجازه می‌دهند. اگر سامانه هم روی دامنه https بیاید (مثلاً `commission.maliyarapp.ir`)، وبینار داخل همان صفحه جلسه و کنار دستور جلسه و رأی‌گیری باز می‌شود.
- **ضبط جلسه:** در این نسخه فعال نیست. ضبط سرور مستقل (Jibri) لازم دارد.
- **وضعیت و گزارش خطا:**
  ```bash
  cd ~/kx21/deploy/webinar
  docker compose ps
  docker compose logs --tail=100 web
  ```
- **توقف:** `cd ~/kx21/deploy/webinar && docker compose down`
- **غیرفعال کردن موقت:** خط `WEBINAR_URL` را از `.env` اصلی پاک کنید و دستور زیر را اجرا کنید. جلسات آنلاین دوباره با «لینک پلتفرم دیگر» کار می‌کنند.
  ```bash
  docker compose up -d --force-recreate api
  ```
