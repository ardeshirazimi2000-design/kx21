# ۶. اعلان‌ها

منبع: `apps/api/src/services/notifications.ts`. هر اعلان در جدول `notifications` ذخیره می‌شود، فوراً روی سوکت کاربر ارسال می‌شود و کانال‌های خارجی به‌صورت غیرهمزمان ارسال می‌شوند (وضعیت هر کانال در `delivery`).

| رویداد | گیرنده | کانال |
|---|---|---|
| دعوت جلسه | دعوت‌شدگان | In-app, Push, SMS, Email |
| تغییر زمان/مکان | دعوت‌شدگان | In-app, Push, SMS |
| لغو جلسه | دعوت‌شدگان | In-app, Push, SMS |
| شروع اعلام حضور | دعوت‌شدگان | In-app, Push |
| یادآوری عدم اعلام حضور (۱۰ دقیقه پس از شروع) | افراد بدون اعلام حضور | In-app, Push |
| عدم حد نصاب | رئیس/دبیر | In-app, Push |
| شروع رأی‌گیری | دارندگان حق رأی | In-app, Push |
| نتیجه رأی | افراد مجاز | In-app |
| ارسال صورتجلسه برای تأیید / برگشت / تأیید نهایی | رئیس / دبیر / همه | In-app, Push |
| ایجاد مصوبه | مسئول اجرا | In-app, Push, Email |
| نزدیک شدن سررسید | مسئول + دبیر | In-app, Push |
| تأخیر مصوبه | مسئول + رئیس + دبیر | In-app, Push, Email |
| ارجاع کارشناسی / پاسخ | کارشناس / ارجاع‌دهنده | In-app, Push (Email) |

ارائه‌دهندگان: Push از طریق Expo Push؛ SMS از طریق کاوه‌نگار (`SMS_PROVIDER=kavenegar`, `KAVENEGAR_API_KEY`)؛ Email در حالت log تا تعیین سرویس SMTP سازمان. Scheduler هر `SCHEDULER_INTERVAL_SECONDS` اجرا شده و هر یادآوری را فقط یک‌بار می‌فرستد.
