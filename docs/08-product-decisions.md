# ۸. تصمیم‌های محصول (بخش ۲۵ سند)

همه موارد زیر **قابل تنظیم** پیاده‌سازی شده‌اند و مقدار پیش‌فرض فعلی باید توسط مالک محصول تأیید شود.

| تصمیم | وضعیت در سامانه | پیش‌فرض |
|---|---|---|
| نصاب قانونی هر کمیسیون | تنظیم به‌ازای کمیسیون (نصف+۱، دو سوم، درصد، عدد ثابت) | نصف+۱ اعضای دارای حق رأی |
| حضور نماینده به جای عضو | `allowProxy` و `quorum.countProxy` | مجاز، در نصاب محاسبه می‌شود |
| امضای دیجیتال | فعلاً هش SHA-256 صورتجلسه تأییدشده + Audit؛ اتصال به امضای دیجیتال/گواهی در فاز بعد | — |
| رأی مخفی/آشکار | انتخاب به‌ازای هر رأی‌گیری + پیش‌فرض کمیسیون؛ نمایش نتیجه برای همه یا فقط ارکان | آشکار، نتیجه برای همه |
| کانال‌های اعلان و SMS | ماتریس اعلان؛ کاوه‌نگار آماده، قابل جایگزینی | Push + In-app؛ SMS/Email در حالت log |
| نگهداری اسناد و داده شخصی | فایل‌ها در volume جدا، حذف فیزیکی پیاده نشده | نیازمند سیاست رسمی |
| قواعد تأیید و انتشار صورتجلسه | دبیر تنظیم ⇒ رئیس تأیید/برگشت ⇒ قفل؛ اعضا فقط نسخه تأییدشده را می‌بینند | همین |
| جلسات آنلاین/ویدئوکنفرانس | نوع جلسه آنلاین/ترکیبی + لینک + حضور آنلاین؛ اتصال API ویدئوکنفرانس در فاز بعد | لینک خارجی |
| قاعده تصویب مصوبه | اکثریت حاضرین / آرای مأخوذه / موافق>مخالف / دو سوم | اکثریت مطلق حاضرین |
| حق رأی دبیر | پیش‌فرض بدون رأی؛ قابل تغییر در عضویت | بدون رأی |
